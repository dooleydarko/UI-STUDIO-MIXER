# Antigravity Code Mixer - Component Copier Extension

A zero-dependency Manifest V3 browser extension to capture HTML and CSS from UI design sites (Uiverse.io, CodePen, etc.) and seamlessly ingest them into the Antigravity 3D Code Mixer Studio.

## How to Install in Google Chrome / Brave / Edge

1. Open Chrome and navigate to `chrome://extensions`.
2. Toggle on **Developer mode** in the top right corner.
3. Click the **Load unpacked** button in the top left.
4. Select the directory:
   `/Users/abcd/.gemini/antigravity/scratch/code-mixer-3d-studio/extension`
5. The extension is now active!

## How to Use

### Method 1: The Floating Quick Button
1. Open any component page on [uiverse.io](https://uiverse.io).
2. You'll see a floating **⚡ Copy to Code Mixer** button in the bottom right corner.
3. Click it — the extension extracts the clean HTML, CSS, and component name and copies it directly to your clipboard.
4. In Antigravity Studio, open the **Quick Intake & Queue** dock (or click **Queue** in the top bar) and click **Paste HTML** & **Paste CSS**, or let auto-enqueue ingest it directly into your **Queue Library**!

### Method 2: Extension Popup
1. Click the Antigravity icon in your browser toolbar.
2. Click **Copy Current Page Code**.
3. Click **Open Studio** to hop straight into your local workspace.
